# The Vault — Smart Money Intelligence

Real-time option flow, dark pool prints, and 13F hedge fund filings.

## Deploy

This project is a single-page HTML app. Deploy instantly on Vercel or Netlify.

### Vercel
1. Push this repo to GitHub
2. Import on vercel.com
3. Select **Other** as framework
4. Deploy — done

### Local
Just open `index.html` in your browser.

## Stack
- Vanilla HTML/CSS/JS — no build step needed
- Finnhub WebSocket for real-time prices
- Tally.so for waitlist signups
- Simulated option flow (swap for Unusual Whales API for real data)
